# Skill & Memory backup rules

- Treat this directory as the portable backup mirror for Maxine's budget workflow.
- When a task changes a spending Skill, classification Memory, reusable classification rule, or deployed web-app feature, refresh the corresponding copy in this directory in the same task.
- Keep paths portable. Prefer locations relative to the project containing `skill&memory/`; never assume the original Mac username or home directory on another device.
- Preserve both `web-app/source/` and the relative-path production build in `web-app/static-site/` after webpage changes.
- Update `VERSION.md` with the date, source commit when available, live URL, and verification summary.
- Never place raw bills, screenshots, exported browser backups, API keys, `.env` files, card/account identifiers, or full personal transactions in this portable bundle.
- Memory files may contain only generalized rules, workflow preferences, source filenames for traceability, and non-sensitive quality checks.
- Do not overwrite user source workbooks. Any workbook output belongs outside this backup bundle.
